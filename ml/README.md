# Machine Learning End To End — Colab notebooks

One notebook per lesson of the **Machine Learning End To End** course, in course order:

| Folder | Lessons |
|---|---|
| `01-prerequisites/` | Sampling, descriptive statistics, probability, inferential statistics, linear algebra, calculus |
| `02-python-for-data-science/` | Environment, Python basics, data structures & OOP, NumPy, pandas, wrangling, visualisation, EDA, file I/O |
| `03-data-engineering/` | Acquisition, databases, scale |
| `04-machine-learning/` | The algorithm and evaluation lessons |
| `05-full-projects/` | The end-to-end projects |
| `06-case-studies/` | Case studies |

Each notebook has the same shape:

1. **Setup** — installs any package Colab does not already have and downloads the lesson's dataset from `data/`.
2. **The lesson's code**, cell by cell, exactly as on the course page, so you can compare your output with the lesson.
3. **Graded exercises** — a starter cell, a check cell that prints ✅ / ❌, and a folded solution. Try before you peek.

Open any notebook with the **Open in Colab** badge at its top, or from the button on the lesson page.
Run cells top to bottom (Runtime → Run all works: unfinished exercises just print a hint).

`data/` holds the datasets the lessons load. See `data/SOURCES.md` for where each one comes from and its licence.
